# 앱인토스 심사 제출용 서비스 설명

'친일파 테스트' 때 "입력해주신 앱 정보만으로는 서비스 확인 및 심사가
어렵습니다"로 한 번 반려됐다. 같은 일을 또 겪지 않도록 처음부터 구체적으로
적어 둔다.

아래 내용은 전부 현재 구현된 사실이다. 없는 기능은 적지 않았다.

---

## 1. 상세 설명 필드에 넣을 문구

### 확장판

사고 싶은 물건의 가격을 넣으면 구매 승인 또는 반려를 찍어 주는 유머
콘텐츠입니다.

가격을 입력하고 세 가지 질문 — 몇 번 쓸 것 같은지, 집에 비슷한 것이 이미
있는지, 지금 술을 마셨는지 — 에 답하면 영수증 모양의 판정서가 나옵니다.

판정서에는 네 가지가 담깁니다.
1. 하루당·1회당 비용 계산과 일상 물가(붕어빵, 아메리카노, 치킨 등)와의 비교
2. 소비 승인율, 핑계 수준(S~F), 내일 후회 확률
3. 그 숫자가 나온 이유를 설명하는 판독 소견 네 줄
4. 구매 승인 / 보류 / 재고 / 반려 도장

"2년 신으면 하루 327원입니다. 자판기 종이컵 커피보다 쌉니다" 같은 식으로
소비를 합리화해 주다가도, 한 달에 한두 번 쓸 물건이면 "하루로 나누는 건
반칙입니다. 1회당 3,319원입니다"라고 되짚습니다. 집에 비슷한 것이 네 개 넘게
있다고 답하면 "정신 차리십시오"가 나옵니다.

판정은 입력한 답에서 기계적으로 계산되며, 실제 재정 조언이 아닌 농담이라는
점을 결과 화면 하단에 명시합니다. 상품을 추천하거나 판매하지 않고, 어떤
쇼핑몰로도 연결하지 않습니다.

로그인이 필요 없고 개인정보를 일절 수집하지 않습니다. 소요 시간은 30초
내외입니다.

### 축약판 (글자 수 제한이 빡빡할 때)

사고 싶은 물건의 가격을 넣고 세 가지 질문에 답하면, 하루당 비용을 계산해
일상 물가와 견주고 구매 승인 또는 반려를 찍어 주는 유머 콘텐츠입니다. 소비
승인율·핑계 수준·내일 후회 확률을 영수증 모양으로 보여줍니다. 상품을
추천하거나 판매하지 않으며, 실제 재정 조언이 아닌 농담임을 화면에 명시합니다.
로그인과 개인정보 수집이 없습니다. 30초 소요.

## 2. 채널톡으로 보낼 내용

안녕하세요. '살까 말까 판독기'의 서비스 내용을 구체적으로 전달드립니다.

### 한 줄 요약

사고 싶은 물건의 가격을 입력하고 세 가지 질문에 답하면, 이상한 논리로 계산한
구매 승인 또는 반려 판정을 영수증 모양으로 받아 보는 유머 콘텐츠입니다.

### 핵심 기능

**1) 가격 입력 (약 10초)**

사고 싶은 물건의 가격을 숫자로 입력합니다. +1만 / +5만 / +10만 / +100만 버튼으로
빠르게 올릴 수 있습니다. 품목 이름은 선택 입력이며 적지 않아도 진행됩니다.

**2) 세 가지 질문 (약 15초)**

| 문항 | 선택지 |
| --- | --- |
| 몇 번 쓸 것 같아? | 거의 매일 / 일주일에 두세 번 / 한 달에 한두 번 / 솔직히 한두 번 |
| 이미 비슷한 거 있어? | 하나도 없다 / 하나 있는데 낡았다 / 두세 개 있다 / 네 개 넘게 있다 |
| 지금 술 마셨어? | 맨정신이다 / 한두 잔 했다 / 많이 마셨다 / 새벽 3시고 안 잤다 |

**3) 판정 영수증**

첫 문항의 답으로 예상 수명과 총 사용 횟수를 정하고(예: 거의 매일 → 2년·600회),
가격을 그것으로 나눠 하루당·1회당 비용을 냅니다. 하루당 금액은 일상 물가
사다리(자판기 커피 500원, 붕어빵 1,000원, 아메리카노 4,500원, 치킨 25,000원,
심야 택시 80,000원 등)에서 바로 위 칸과 견줍니다.

세 지표를 함께 보여줍니다.

- **소비 승인율** — 판정을 가르는 값입니다. 66% 이상 승인, 50% 이상 보류,
  34% 이상 재고, 그 아래 반려입니다.
- **핑계 수준 (S~F)** — 얼마나 그럴듯하게 포장할 수 있는가입니다. 하루당이
  쌀수록, 자주 쓸수록 오릅니다.
- **내일 후회 확률** — 음주 여부와 중복 보유가 가장 크게 밀어 올립니다.

판정 소견 네 줄이 그 숫자가 나온 이유를 설명하고, 마지막에 구매 승인 / 보류 /
재고 / 반려 도장이 찍힙니다.

**4) 결과 공유**

토스 네이티브 공유 시트(`Share.sendMessage`)로 판정 결과를 공유할 수 있습니다.

### 이용 방식

1. 앱 진입 → 가격 입력 → '판독 시작'
2. 세 문항을 순서대로 터치 (앞 문항으로 되돌아갈 수 있습니다)
3. 영수증 화면에서 판정과 소견 확인
4. '결과 보내기' 또는 '다시 판독하기'

별도 가입, 로그인, 결제, 본인 확인 단계가 없습니다.

### 권한 및 개인정보

- **요청 권한 없음** (`permissions: []`). 카메라·사진첩·연락처·위치를 모두
  사용하지 않습니다.
- **서버가 없습니다.** 판정은 앱 안에서 전부 계산됩니다. 입력한 금액과 품목
  이름은 기기 밖으로 나가지 않으며, 어디에도 저장되지 않습니다. 앱을 닫으면
  사라집니다.
- **로그인 없음**, 이름·연락처·생년월일 등 개인 식별 정보를 일절 수집하지
  않습니다.
- 미니앱 내 광고가 없습니다.

### 심사 시 참고해 주실 점

소비·금액을 다루는 앱이라 금융 서비스로 보이실 수 있어 미리 말씀드립니다.

- **금융 서비스가 아닙니다.** 결제, 송금, 대출, 투자, 자산 조회 기능이 하나도
  없습니다. 토스의 결제·인증 API도 사용하지 않습니다.
- **실제 재정 조언이 아닙니다.** 결과 화면 하단에 "본 판독은 농담입니다.
  숫자는 입력하신 답에서 기계적으로 계산된 것이고, 어떤 것도 실제 재정 조언이
  아닙니다"를 상시 노출합니다. 첫 화면에도 "본 판독기는 아무 근거도 대지
  않습니다. 결제는 본인 책임입니다"를 적어 두었습니다.
- **상품을 팔지 않습니다.** 특정 상품·브랜드·쇼핑몰을 추천하거나 연결하지
  않습니다. 제휴 링크가 없고, 외부로 나가는 링크 자체가 없습니다.
- **소비를 부추기지 않습니다.** 가능한 답 조합을 고르게 훑으면 승인은 5분의 1
  정도이고 나머지 80%는 보류·재고·반려입니다. 집에 비슷한 물건이 많거나 술을
  마신 상태면 승인율이 크게 떨어집니다.
- **음주 문항에 대하여.** 술을 마셨는지 묻는 것은 충동구매를 되짚기 위한
  장치입니다. 음주를 권하거나 미화하는 문구는 없으며, 취했다고 답하면 "지금
  누르는 결제는 내일의 당신이 갚습니다"처럼 만류하는 쪽으로 결과가 나옵니다.
- **판정은 결정적입니다.** 난수를 쓰지 않아 같은 입력에는 언제나 같은 결과가
  나옵니다. 판정 로직은 `src/verdict.ts` 한 파일에 모여 있고, 자동 검사
  (`npm run verify`)로 1,216가지 조합의 성질을 확인하고 있습니다.

추가로 필요한 자료가 있으면 알려주시면 바로 보완하겠습니다. 감사합니다.
