# 친일파 테스트

1936년부터 1945년까지, 열여섯 번의 갈림길로 구성한 역사 선택 테스트.
그 시대에 놓였다면 어디쯤 서 있었을지를 아홉 가지 유형으로 비추어 본다.

실존 인물을 판정하지 않는다. 이름을 넣어 친일 여부를 가리는 기능은 없고
앞으로도 넣지 않는다.

## 개발

```bash
npm install
npm run dev      # http://localhost:3000
npm run build
npm run lint
```

## 구조

| 파일 | 역할 |
| --- | --- |
| `app/questions.ts` | 채점 문항 15개 + 에필로그 1개 |
| `app/types.ts` | 결과 유형 9종과 판정 로직(`decide`) |
| `app/quiz.tsx` | 진행·결과 화면 (클라이언트) |
| `app/r/[type]/` | 유형별 공유·색인용 정적 페이지 |
| `app/api/stats/` | 유형·꺾인 단계 익명 집계 |
| `scripts/calibrate.mts` | 판정 임계값 보정용 몬테카를로 |

## 채점

선택지마다 네 값을 붙인다.

- `b` 신념(공동체) 0–2
- `a` 적극성 0–2
- `d` 태도 +1 정면 / −1 우회
- `r` 신념을 지킨 선택인가 — `false`로 처음 답한 단계가 "꺾인 지점"
- `inform` 사람을 넘긴 선택인가 — 밀정형 판정에만 쓴다

세 축은 서로 독립이어야 한다. "저항 = 신념 높음 + 적극적 + 정면"으로 몰아서
매기면 사분면 구조가 무너져 한 유형으로 쏠린다. 조용한 거부(신념 높음 +
소극), 열성적 협력(신념 낮음 + 적극), 순순한 순응(낮음 + 소극 + 정면)이
고루 있어야 한다.

**문항이나 점수를 고치면 반드시 보정을 다시 돌릴 것.**

```bash
npm run calibrate
```

두 가지 모집단(성향이 고른 쪽 / 저항으로 쏠린 쪽)을 시뮬레이션해 아홉 유형이
모두 도달 가능하고 어느 하나가 화면을 독점하지 않는 임계값을 찾는다. 출력된
값을 `app/types.ts`의 임계값과 각 유형 `pct`, `app/quiz.tsx`의 `BASE`에
반영한다.

## 환경변수

전부 선택이다. 없으면 집계 기능만 조용히 꺼진다.

| 변수 | 용도 |
| --- | --- |
| `KV_REST_API_URL` / `KV_REST_API_TOKEN` | Upstash Redis (집계·방문자 수) |
| `NEXT_PUBLIC_SITE_URL` | 커스텀 도메인을 붙였을 때의 정식 주소 |

Upstash를 붙이지 않으면 결과 화면은 시뮬레이션 기본 분포를 보여주고, 화면에
그 사실을 함께 표시한다.
