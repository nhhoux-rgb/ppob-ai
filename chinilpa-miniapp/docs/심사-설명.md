# 앱인토스 심사 제출용 서비스 설명

반려 사유: "입력해주신 앱 정보만으로는 서비스 확인 및 심사가 어렵습니다.
채널톡으로 실제 제공 예정인 서비스의 구체적인 내용(핵심 기능·이용 방식 등)을
전달해 주세요."

아래 내용은 전부 현재 구현된 사실이다. 없는 기능을 적지 않았다.

---

## 1. 상세 설명 필드에 넣을 문구

### 확장판

일제강점기(1936~1945)를 배경으로 한 역사 선택형 테스트입니다.

실제로 있었던 제도와 사건 — 황국신민서사 제창, 신사참배 동원, 애국반,
창씨개명, 조선어 신문 폐간, 금속 공출, 학도지원병 권유, 징용 — 을 배경으로
한 16개의 상황이 연도순으로 제시됩니다. 각 상황마다 세 개의 선택지가 있고,
모든 선택지에는 대가가 따릅니다. 초반 문항은 잃을 것이 거의 없지만 뒤로
갈수록 직업, 재산, 가족의 안전이 걸립니다.

응답이 끝나면 세 가지를 보여드립니다.
1. 아홉 가지 유형 중 당신에게 해당하는 결과와 그 유형에 대한 해설
2. 당신이 처음으로 신념을 놓은 시점(꺾인 지점)과 다른 응답자와의 비교
3. 해방 다음 날을 다루는 마지막 질문에 대한 당신의 답

특정 실존 인물을 평가하거나 판정하지 않습니다. 이름을 입력받는 기능 자체가
없으며, 그 시대에 존재했던 삶의 방식을 유형화해 보여주는 역사 학습
콘텐츠입니다. 가장 흔한 결과는 영웅도 반역자도 아닌 "생계형 순응자"이며,
이는 당시 조선인의 절대다수가 그 자리에 있었다는 역사적 사실을 그대로
반영한 것입니다.

로그인이 필요 없고 개인정보를 일절 수집하지 않습니다. 소요 시간은 3분
내외입니다.

### 축약판 (글자 수 제한이 빡빡할 때)

일제강점기(1936~1945)의 실제 제도와 사건을 배경으로 한 16개 상황에
답하면서, 그 시대에 놓였다면 어떤 선택을 했을지 확인하는 역사 선택형
테스트입니다. 결과로 아홉 가지 유형 중 하나와 함께, 당신이 처음으로 신념을
놓은 시점을 다른 응답자와 비교해 보여줍니다. 실존 인물을 평가하지 않는 역사
학습 콘텐츠이며, 로그인과 개인정보 수집이 없습니다. 3분 소요.

## 2. 채널톡으로 보낼 내용

안녕하세요. '친일파 테스트' 앱 정보 보완 요청 받고 서비스 내용을 구체적으로
전달드립니다.

### 한 줄 요약

일제강점기(1936~1945)를 배경으로, 실제 있었던 상황에 어떤 선택을 했을지
16문항으로 답하고 아홉 가지 유형 중 하나의 결과를 받는 역사 선택형
테스트입니다.

### 핵심 기능

**1) 연도순 상황 제시 (16문항, 약 3분)**

1936년부터 1945년까지 실제 제도와 사건을 배경으로 한 상황이 시간 순서대로
제시됩니다.

| 시기 | 다루는 상황 |
| --- | --- |
| 1936 | 손기정 일장기 말소 보도 |
| 1937 | 황국신민서사 제창, 신사참배 동원 |
| 1938 | 애국부인회 위문대, 애국반장 |
| 1940 | 창씨개명, 조선어 신문 강제 폐간 |
| 1941 | 학교에서의 조선어 사용, 금속(놋그릇) 공출 |
| 1942 | 단파방송 밀청, 국방헌금 |
| 1943 | 학도지원병 권유 |
| 1944 | 징용 영장, 이웃에 대한 경찰 조사 |
| 1945 | 쫓기는 사람의 은신 요청, 해방 다음 날 |

각 문항은 세 개의 선택지를 제공하며, 모든 선택지에 대가가 따릅니다. 첫
문항은 술자리에서 한마디 하는 정도로 잃을 것이 없지만, 마지막에는 가족의
안전이 걸립니다.

**2) 결과 판정 (아홉 가지 유형)**

응답을 신념·적극성·태도 세 축으로 집계해 아래 아홉 유형 중 하나를 보여줍니다.

무장투쟁형 「총을 든 사람」 / 조직가형 「이름 없는 연락책」 /
은둔 지식인형 「붓을 꺾은 사람」 / 내면저항형 「마음속에만 태극기」 /
생계형 순응자 「그저 살아낸 사람」 / 이중생활형 「낮과 밤이 다른 사람」 /
기회주의 사업가형 「전쟁은 기회였다」 / 전향 지식인형 「설득당한 붓」 /
밀정형 「가장 가까운 배신」

각 유형마다 해설, 관련 역사적 기록 한 줄, 그리고 "같은 성향이어도 다른
처지였다면 결과가 달랐을 것"이라는 관점을 함께 제공합니다.

**3) 꺾인 지점 분석**

최종 유형만이 아니라, 이용자가 **처음으로 신념을 놓은 시점**을 함께
보여줍니다. 단계별 분포 그래프에 본인 위치를 표시하고 "당신보다 늦게까지
버틴 사람은 N%"를 안내합니다.

**4) 해방 다음 날 (에필로그)**

마지막 문항은 1945년 8월 16일을 다룹니다. 해방 이후에는 옳은 선택의 방향
자체가 뒤집히기 때문에 이 문항은 점수에 반영하지 않고, 결과 화면에 이용자의
답을 한 줄로 되돌려주기만 합니다.

**5) 결과 공유**

토스 네이티브 공유 시트(Share.sendMessage)로 결과를 공유할 수 있습니다.

### 이용 방식

1. 앱 진입 → 표지에서 '조사를 시작한다' 버튼
2. 16개 문항을 순서대로 진행 (문항당 선택지 3개 중 하나 터치, 되돌아가기 없음)
3. 결과 화면에서 유형·해설·꺾인 지점 분포 확인
4. '결과 공유하기' 또는 '다시 조사받기'

별도 가입, 로그인, 결제, 정보 입력 단계가 없습니다.

### 권한 및 개인정보

- **요청 권한 없음** (`permissions: []`). 카메라·사진첩·연락처·위치 모두 사용하지 않습니다.
- **로그인 없음**, 이름·연락처·생년월일 등 개인 식별 정보를 일절 수집하지 않습니다.
- 결과 화면의 비율 표시를 위해 **"어떤 유형이 나왔는가"와 "몇 단계에서 물러섰는가" 두 가지만 숫자로 합산**합니다. 누가 무엇을 골랐는지는 저장하지 않으며, 개별 응답을 되짚어 특정인을 알아내는 것은 구조적으로 불가능합니다.
- 미니앱 내 광고가 없습니다.

### 심사 시 참고해 주실 점

서비스명에 '친일파'가 들어가 민감하게 보이실 수 있어 미리 말씀드립니다.

- **실존 인물을 평가하지 않습니다.** 이름을 검색하거나 입력받는 기능이 아예 없고, 앞으로도 추가할 계획이 없습니다. 특정 개인·가문·단체를 지목하거나 명단화하지 않습니다.
- **누구를 친일파로 규정하는 서비스가 아닙니다.** 이용자 본인이 그 시대에 놓였다면 어떤 선택을 했을지를 비추어 보는 콘텐츠입니다.
- **결론이 낙인이 아니라 이해입니다.** 가장 흔하게 나오는 결과는 영웅도 반역자도 아닌 '생계형 순응자'이며, 결과 화면에서 "당시 조선인의 절대다수가 여기 있었다"는 점을 명시합니다. 특정 집단을 비하하거나 정치적 주장을 선동하는 내용이 없습니다.
- **역사적 사실에 근거합니다.** 문항의 모든 배경(황국신민서사, 신사참배, 애국반, 창씨개명, 조선어 신문 폐간, 금속 공출, 단파방송 밀청 사건, 학도지원병, 징용)은 실제 제도와 사건입니다. 개별 인물과 대화는 창작이지만 배경은 기록에 근거합니다.
- **출처를 공개하고 있습니다.** 웹 버전에 출처 페이지를 별도로 운영하며, 표지에 인용한 수치(친일인명사전 등재 4,389명 / 독립유공자 서훈 약 1만 8천 명 / 식민지 조선 인구 약 2,500만)의 근거를 밝히고 있습니다.
- **통계 표기를 오해 없이 했습니다.** 결과의 비율은 "이 테스트 응답자의 분포"이며 당시 조선인의 실제 분포가 아니라는 점을 화면에 함께 적어 두었습니다.
- 앱 하단에 "실존 인물을 평가하지 않는 역사 학습 콘텐츠입니다"를 상시 노출합니다.
