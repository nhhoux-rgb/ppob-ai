# 5초 상식퀴즈 최종 전달 파일

## 서비스 정보

- 앱 이름: 5초 상식퀴즈
- appName: `five-second-brief`
- 앱 유형: 앱인토스 게임(WebView)
- 백엔드: Supabase

## 업로드 파일

- `five-second-brief.ait`: 등급분류·출시 준비용 앱 번들
- 공식 랭킹과 실제 광고는 제외된 버전
- 분야별 문제 풀 100개 중 20개를 출제하는 AI 퀴즈 구조

## 디자인 파일

- `logo-white-600.png`: 앱 로고, 600×600
- `game-thumbnail-1932x828.png`: 게임 썸네일
- `screenshot-01-category-636x1048.png`: 분야 선택 소개 이미지
- `screenshot-02-quiz-636x1048.png`: 퀴즈 플레이 소개 이미지
- `screenshot-03-result-636x1048.png`: 시간 단축·완주 소개 이미지
- `landscape-screenshot-1504x741.png`: 가로형 스크린샷

## 등급분류 자료

- `rating-application-pack.docx`: 수정 가능한 신청자료
- `rating-application-pack.pdf`: 제출·검토용 PDF

신청자명, 사업자 정보, 연락처, 약관 URL 등 빈칸은 신청자가 입력해야 합니다. 홍보용 소개 이미지는 실제 플레이 증빙 화면을 대체하지 않으므로, 심사 제출 시 토스 테스트 환경의 원본 플레이 화면과 실행 영상을 별도로 촬영해야 합니다.

## 소스 및 운영자료

- `app-source`: 앱인토스 프런트엔드 소스
- `backend`: Supabase 스키마, 마이그레이션, Edge Function 소스
- `guides`: 문제 풀·배포·운영 안내

## 출시 전 필수 확인

1. 게임제작업 등록과 게임물 등급분류를 완료합니다.
2. 개인정보 처리방침, 이용약관, 고객문의 이메일을 등록합니다.
3. 실제 토스 앱에서 로그인, 문제 수신, 정답 판정, 공유 기능을 끝까지 테스트합니다.
4. 등급분류 신청자료와 제출하는 AIT의 광고·결제·랭킹 상태가 일치하는지 확인합니다.
5. 보상형 광고나 유료 도전권을 추가할 때는 등급분류 변경·신고 필요 여부를 먼저 확인합니다.
