# 서버 문제풀 채우기 (분야별 100문제) + 서버 출제

앱은 `ai-quiz` 함수를 통해 **서버 문제풀에서 20문제**를 받아 플레이합니다.
`ai-quiz`는 난이도(1~5)별로 4개씩 뽑기 때문에, **난이도별 4개 이상**이 있어야 서버 출제가 되고,
없으면 앱이 로컬 예비문제(폴백)로 내려갑니다.

두 단계로 채웁니다: **① 시드(즉시 동작) → ② ai-pool-maintain(100까지 자동 보충).**

## 0. (미실행 시) 스키마·마이그레이션 먼저

SQL Editor에서 순서대로 실행(이미 했으면 건너뛰기, 모두 멱등):

1. `backend/supabase-initial-schema.sql`
2. `backend/supabase-pool-migration.sql`  ← `question_exposures`, `quiz_sets.player_key` 필요(ai-quiz가 사용)
3. `backend/supabase-leaderboard-schema.sql`

> ai-quiz가 이미 동작 중이면 1·2는 보통 완료된 상태예요.

## ① 시드 넣기 (즉시 서버 출제 가능)

SQL Editor에 **`backend/pool/seed-all-160.sql`** 전체를 붙여넣고 **Run**.
- 분야별 40문제(난이도별 8개), 총 160문제가 `approved`로 들어갑니다.
- 여러 번 실행해도 중복되지 않아요(content_hash 기준).
- 이 시점부터 앱이 **서버에서 문제를 불러와** 출제합니다(폴백 아님).

확인: 각 분야 결과에 난이도 1~5가 모두 count ≥ 8 로 나오면 정상.

## ② 100까지 자동 보충 (ai-pool-maintain)

AI가 공식 출처를 웹검색·검증해 부족한 난이도를 채웁니다(분야별 100/난이도20까지).

1. **Supabase → Edge Functions → Secrets** 에 두 값 추가:
   - `OPENAI_API_KEY` : OpenAI 키
   - `POOL_MAINTAIN_SECRET` : 임의의 비밀 문자열(예: 랜덤 32자)
2. 스크립트 실행(로컬 터미널):
   ```bash
   cd five-second-brief/backend/pool
   POOL_MAINTAIN_SECRET='위에서 정한 값' bash fill-pool.sh
   ```
   - 분야별로 `full`/`balanced`가 나올 때까지 반복 호출합니다.
   - `gpt-5.4-mini` + 웹검색으로 생성하며, 공식 도메인 출처만 통과시켜 저장합니다.
3. (선택) 주기적 유지: Supabase **cron**으로 `ai-pool-maintain` 을 `{"category":"auto"}` 로 15분마다 호출하면 풀이 계속 신선하게 유지됩니다.

## 확인

- 앱에서 한 분야를 5판 연속 플레이 → 매판 다른 문제가 나오면 성공.
- 카운트다운 화면에 "오늘의 AI 퀴즈"로 표시되면 서버 출제(폴백 아님)예요.
  ("안전 문제은행으로 시작해요"가 뜨면 아직 폴백 → 난이도별 4개 미만 분야가 있는지 확인).

## 참고

- 시드 40개만으로도 서버 출제는 되지만, 같은 난이도 문제가 2판이면 소진돼 반복될 수 있어요. ②로 100까지 채우면 반복이 크게 줄어요.
- 문제 내용을 수정/추가하려면 `backend/pool/build-seed.mjs` 의 DATA를 고치고 `node build-seed.mjs` 로 SQL을 다시 생성하세요.
