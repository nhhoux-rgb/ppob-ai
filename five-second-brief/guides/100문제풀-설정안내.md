# 분야별 100문제 풀 설정

## 1. DB 변경

SQL Editor에서 `supabase-pool-migration.sql`을 한 번 실행합니다.

## 2. 보충 함수 배포

Edge Functions에서 `ai-pool-maintain` 함수를 만들고 `supabase-edge-ai-pool-maintain.ts`를 배포합니다. JWT 검증은 OFF로 설정합니다.

Secrets에 충분히 긴 임의 문자열을 추가합니다.

- 이름: `POOL_MAINTAIN_SECRET`
- 값: 비밀번호 생성기로 만든 32자 이상의 무작위 문자열

이 값은 채팅이나 앱 코드에 넣지 않습니다.

## 3. 게임 함수 갱신

기존 `ai-quiz` 코드를 최신 `supabase-edge-ai-quiz.ts`로 교체하고 재배포합니다.

## 4. 문제 풀 채우기

`ai-pool-maintain` Test 화면에서:

- Method: POST
- Header: `x-pool-secret` = Supabase Secret에 저장한 동일 문자열
- Body: `{"category":"auto"}`

한 번 호출할 때 부족한 한 분야·난이도에 최대 20문제를 추가합니다. 초기에는 여러 번 실행해야 하며 응답이 `full`이면 100개가 확보된 것입니다.

## 5. 완전 자동화

Supabase Cron에서 10분마다 `ai-pool-maintain`을 POST 호출하도록 예약합니다. Body는 `{"category":"auto"}`, Header에는 `x-pool-secret`을 넣습니다. Cron UI에서 비밀 헤더 저장을 지원하지 않으면 비밀을 SQL에 직접 쓰지 말고 Supabase Vault 연동 방식으로 설정합니다.

운영 중에는 함수가 활성 문제 수를 먼저 확인하므로 100개가 차 있으면 AI를 호출하지 않습니다. 만료된 문제로 100개 미만이 될 때만 20개씩 보충합니다.

## 출제 규칙

- 분야별 활성 문제 풀: 100개
- 난이도별 목표: 20개
- 한 게임: 난이도별 4개, 총 20개
- 이미 본 문제 우선 제외
- 100개를 모두 본 뒤 가장 오래전에 본 문제부터 재출제
- 제한시간: 5초, 4.5초, 4초, 3.5초, 3초
