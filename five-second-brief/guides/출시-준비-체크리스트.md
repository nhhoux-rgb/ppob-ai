# 5초 브리핑 출시 준비 상태

## 구현 완료

- 단일 `오늘의 AI 퀴즈` UX
- 경제/시사/국제/역사 선택
- 날짜·분야별 AI 20문제 생성 및 캐시
- 허용된 공식기관 출처 검색
- 질문 형식·보기 중복·출처 도메인 자동 검증
- 정답을 문제 조회 응답에서 제외
- 별도 Edge Function 서버 채점
- 5초 → 3초 단계별 제한시간
- 오답/시간 초과 즉시 종료
- AI 장애 시 로컬 문제은행 fallback
- 보상형 광고 및 공유 SDK 어댑터 경계

## 출시 전 반드시 실제 연동할 항목

### 앱인토스 콘솔

- 확정 appName
- 게임 앱 유형 및 게임 프로필/리더보드 승인
- 토스 로그인 신청
- 보상형 광고 그룹 ID
- 고객문의 이메일
- 개인정보 처리방침 URL
- 이용약관 URL
- 앱 아이콘 600×600 및 썸네일
- 게임 등급분류 증명서 또는 스토어 등급분류 링크

### 서버

- 토스 로그인 인가 코드 교환용 mTLS 서버
- 실제 Toss userKey와 app_users 연결
- attempts/attempt_answers 서버 기록
- 서버 시각 기반 5→3초 검증
- 실제 일일 랭킹 API
- 광고 보상 멱등 지급
- 도전권 원장과 구매 복원
- 문제 신고 및 자동 비활성화
- AI API 사용량/비용 한도와 장애 알림

## 현재 출시 차단 항목

현재 프로토타입의 사용자, 광고, 랭킹은 모의 어댑터입니다. 화면은 정상 동작하지만 실제 출시 전에 아래 값이 있어야 교체할 수 있습니다.

1. 앱인토스 `appName`
2. 보상형 광고 그룹 ID
3. 토스 로그인 Client ID 및 mTLS 인증서 준비 여부
4. 게임센터 리더보드 승인 여부
5. 개인정보 처리방침과 고객센터 공개 URL

## 권장 출시 순서

1. 앱 정보 등록과 게임 등급분류 시작
2. 토스 로그인·광고·게임센터 신청
3. 실제 사용자 세션·기록·랭킹 연결
4. AI 문제 7일간 내부 품질 테스트
5. 샌드박스에서 로그인/광고/백그라운드/네트워크 장애 테스트
6. 운영·기능·디자인·보안 검수 제출

## 출시 판정

현재 상태: **기능 MVP 완료, 실제 플랫폼 인증·랭킹·광고 연동 전**

콘솔 발급값이 준비되면 출시용 SDK 프로젝트와 `.ait` 패키지를 만들 수 있습니다.
