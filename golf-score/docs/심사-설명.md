# 앱인토스 심사 제출용 서비스 설명

같은 저장소의 '친일파 테스트'가 "입력해주신 앱 정보만으로는 서비스 확인 및
심사가 어렵습니다"로 한 번 반려된 적이 있다. 그래서 이번에는 제출 전에 설명을
먼저 준비해 둔다.

아래 내용은 전부 현재 구현된 사실이다. 없는 기능을 적지 않았다.

---

## 1. 상세 설명 필드에 넣을 문구

### 확장판

골프 라운드를 홀별로 기록하고, 끝나면 스코어와 함께 "무엇 때문에 타수를
잃었는지"를 돌려주는 개인 기록장입니다.

구장 이름과 날짜, 티업 시간을 적고 1번홀부터 시작합니다. 홀마다 파(3·4·5)를
고르고, 샷마다 사용한 클럽(드라이버·우드·유틸·아이언·웨지 16종)과 그 결과를
남깁니다. 결과는 좌우 OB, 좌우 해저드, 좌우 러프, 벙커, 뒤땅, 탑볼, 뽕샷,
생크 중에서 고르고, 잘 친 샷은 기본값이라 누를 것이 없습니다. 마지막으로 그
홀의 퍼트 수를 넣으면 타수가 자동으로 계산됩니다.

라운드가 끝나면 네 가지를 보여드립니다.

1. 홀별 스코어카드와 총타수, 전·후반 기록
2. 라운딩 분석 — 미스가 좌우 어느 쪽으로 쏠렸는지, 뒤땅·탑볼이 몇 번
   나왔는지, 벌타로 몇 타를 잃었는지, 퍼트·파온율·페어웨이 안착률·파별
   평균·클럽별 안정도
3. 한줄요약 — 그날 가장 큰 손실 원인과 가장 잘한 것을 한 문장으로
4. 지난 기록과의 비교 — 최근 라운드 평균 대비 타수·퍼트·벌타의 변화와,
   나아지고 있는지에 대한 판정

기록은 이용자의 기기 안에만 저장됩니다. 로그인과 회원가입이 없고, 서버로
전송되는 정보가 없으며, 요청하는 권한도 없습니다.

### 축약판 (글자 수 제한이 빡빡할 때)

골프 라운드를 홀별로 기록하는 개인 기록장입니다. 샷마다 클럽과 결과(OB·해저드
·뒤땅·탑볼 등)를, 홀마다 퍼트 수를 넣으면 타수가 자동 계산됩니다. 라운드가
끝나면 스코어카드와 함께 미스가 어느 쪽으로 쏠렸는지·벌타로 몇 타를 잃었는지
같은 분석과 한줄요약을 주고, 지난 라운드와 견주어 나아지고 있는지 알려줍니다.
로그인·서버 전송·권한 요청이 없고 기록은 기기 안에만 남습니다.

## 2. 채널톡으로 보낼 내용

안녕하세요. '골프 스코어 계산기' 서비스 내용을 구체적으로 전달드립니다.

### 한 줄 요약

골프 라운드를 홀별로 기록하면 타수를 계산해 주고, 라운드가 끝나면 미스 유형과
지난 기록 대비 변화를 분석해 주는 개인 기록장입니다.

### 핵심 기능

**1) 라운드 시작 (구장·날짜·티업 시간)**

구장 이름, 날짜, 티업 시간, 홀 수(9홀 또는 18홀), OB 처리 규칙을 정하고
시작합니다. 전에 갔던 구장은 버튼으로 다시 고를 수 있습니다.

**2) 홀별 입력**

| 항목 | 입력 방식 |
| --- | --- |
| 파 | 3 · 4 · 5 중 선택 (홀마다 변경 가능) |
| 샷별 클럽 | 드라이버, 3·5번 우드, 3·4·5 유틸, 4~9번 아이언, 피칭, 52·56·60도 (16종) |
| 샷별 결과 | 정타 / 좌·우 OB / 좌·우 해저드 / 좌·우 러프 / 벙커 / 뒤땅 / 탑볼 / 뽕샷 / 생크 |
| 샷 개수 | 파에 맞춰 기본 제공, 필요하면 추가·삭제 |
| 퍼트 | 홀마다 개수 입력 |

샷 결과의 기본값이 '정타'이고 샷 줄도 파에 맞춰 미리 깔려 있어서, 잘 친 홀은
아무것도 누르지 않고 다음 홀로 넘어갈 수 있습니다. 미스만 찍으면 됩니다.

**3) 타수 계산**

`홀 스코어 = 친 샷 수 + 벌타 + 퍼트 수` 로 계산합니다.

OB 처리는 골프장 로컬룰마다 달라 라운드마다 고르게 했습니다. 국내에서 흔한
특설티(전진티)는 벌타 2, 원래 자리에서 다시 치는 정규 규칙은 벌타 1로
셉니다. 해저드는 벌타 1이고, 뒤땅·탑볼·뽕샷·생크는 벌타가 없는 미스 기록으로만
남습니다.

**4) 라운딩 분석**

라운드가 끝나면 입력된 기록에서 다음을 계산해 보여줍니다.

- 스코어 구성 (버디·파·보기·더블 홀 수)
- 방향 편향 — 미스가 좌우 어느 쪽으로 쏠렸는지
- 임팩트 미스 — 뒤땅·탑볼·뽕샷·생크 각각 몇 회
- 벌타 — 총 몇 타, OB·해저드 각각 몇 회
- 퍼트 — 총 개수, 홀당 평균, 3퍼트 홀 수, 원퍼트 홀 수
- 파온율(GIR), 페어웨이 안착률
- 파3·파4·파5 평균 타수
- 전·후반 타수 차이
- 클럽별 안정도

**5) 한줄요약**

위 항목에 "이것 때문에 잃은 타수"로 가중치를 매겨, 가장 큰 손실 원인 하나와
가장 잘한 것 하나를 한 문장으로 만들어 줍니다.

**6) 지난 기록과의 비교**

최근 5라운드 평균과 견주어 타수·퍼트·벌타의 변화를 보여주고, 나아지고 있는지
판정합니다. 9홀과 18홀을 섞어 쳐도 비교되도록 전부 18홀 환산 타수로
견줍니다. 다만 **이전 기록이 2개는 있어야**(총 3라운드) 판정을 내놓습니다.
표본이 부족할 때는 "몇 라운드 더 쌓이면 견줘 드립니다"라고만 안내합니다.

**7) 기록 공유**

토스 네이티브 공유 시트(Share.sendMessage)로 그날의 스코어와 한줄요약을
공유할 수 있습니다. 공유는 이용자가 버튼을 눌렀을 때만 동작합니다.

### 이용 방식

1. 앱 진입 → '새 라운드 시작'
2. 구장·날짜·티업 시간·홀 수·OB 규칙 입력 → '1번홀부터 시작'
3. 홀마다 파·샷·퍼트를 넣고 '다음 홀'
4. 마지막 홀에서 '라운드 끝내기' → 스코어카드·분석·한줄요약 확인
5. 홈 화면에서 지난 기록을 다시 열어 볼 수 있음

도중에 앱이 종료돼도 홈 화면의 '이어서 하기'로 그 홀부터 다시 시작합니다.
별도 가입, 로그인, 결제 단계가 없습니다.

### 권한 및 개인정보

- **요청 권한 없음** (`permissions: []`). 카메라·사진첩·연락처·위치를 모두
  사용하지 않습니다.
- **로그인 없음.** 이름·연락처·생년월일 등 개인 식별 정보를 입력받는 화면이
  아예 없습니다.
- **서버로 나가는 정보가 없습니다.** 앱 코드 어디에도 네트워크 호출이 없고,
  라운드 기록은 토스 `Storage`(기기 내 저장소)에만 남습니다. 골프장은 통신이
  자주 끊기고 라운드 하나를 넣는 데 네 시간이 걸리기 때문에, 설계 단계에서
  네트워크 의존을 없앴습니다.
- **미니앱 내 광고가 없습니다.**
- 이용자가 원하면 기록을 화면에서 개별 삭제할 수 있습니다.

### 사용하는 네이티브 API

| 용도 | API |
| --- | --- |
| 라운드 기록 저장 | `Storage` |
| 라운드 중 화면 꺼짐 방지 | `Screen.setAwakeMode` |
| 결과 공유 | `Share.sendMessage` |
| 터치 진동 | `Device.triggerHaptic` |
| 노치·홈 인디케이터 대응 | `SafeArea` |

라운드 중 화면 꺼짐 방지는 홀 입력 화면에 있는 동안만 켜지고, 그 화면을
벗어나면 원래대로 되돌립니다.

### 심사 시 참고해 주실 점

- 스코어 계산 로직은 자동 검증을 붙여 두었습니다(`npm test`). 벌타 처리,
  파온 판정, 전·후반 합계, 추세 비교를 41개 항목으로 확인합니다.
- 제출용 스크린샷은 목업이 아니라 빌드된 앱을 실제로 캡처한 것입니다
  (`npm run shots`). 화면에 보이는 타수와 분석은 예시 라운드로 앱이 실제
  계산한 값입니다.
- 이 앱에는 다른 이용자의 수치가 화면에 등장하지 않습니다. 순위표도, 이용자
  수 표시도 없습니다. 오직 본인의 기록만 다룹니다.

추가로 필요한 자료가 있으면 알려주시면 바로 보완하겠습니다. 감사합니다.
